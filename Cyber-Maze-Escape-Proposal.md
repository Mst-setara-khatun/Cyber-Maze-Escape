## 1. Introduction
NEON SHADOWS: Escape the Cyber Maze is a 2D cyberpunk-themed maze adventure game developed using Python and Pygame CE. The player explores a procedurally generated maze, interacts with cyber terminals, answers computer science quiz questions, avoids enemies, and unlocks exits to progress through multiple levels.

## 2. Problem Statement
Traditional maze games often focus only on navigation. This project combines maze exploration with quiz-based interaction to create a more engaging gameplay experience. Players must navigate maze paths, avoid enemies, and answer timed questions to unlock their way forward.

## 3. Aim and Objectives
- Develop an interactive 2D maze adventure game.
- Implement procedural maze generation using a randomized DFS-based maze-carving approach.
- Create keyboard-controlled player movement.
- Implement wall collision detection.
- Develop interactive quiz terminals.
- Add countdown, score, and lives systems.
- Implement enemy movement and collision interactions.
- Design multiple levels and game-state screens.
- Demonstrate computer graphics and game programming concepts.

## 4. Proposed Gameplay
The player navigates a maze using WASD or arrow keys. A cyber terminal provides computer science quiz challenges. The player must answer within the time limit. A correct answer unlocks the exit. Enemies patrol designated paths and can affect the player's lives. The player reaches the unlocked exit to progress.

## 5. Main Features

## 6. Computer Graphics Concepts and Algorithms
- **2D Rendering:** Drawing the maze, player, enemies, interface elements, and game objects.
- **Grid-Based Representation:** Representing maze structure through rows and columns.
- **Procedural Maze Generation:** Randomized Depth-First Search (DFS) maze-carving approach.
- **Collision Detection:** Checking player movement against maze walls and handling enemy interactions.
- **Event Handling:** Processing keyboard input and game events.
- **Game Loop:** Updating game states and rendering frames continuously.
- **Animation and Timing:** Managing timed events, enemy movement, and quiz countdown.
- **GUI Design:** Creating menus, HUD, buttons, status messages, and result screens.
