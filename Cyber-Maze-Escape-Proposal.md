## 1. Introduction
NEON SHADOWS is a 2D cyberpunk maze adventure game. Players explore procedurally generated mazes, access cyber terminals, solve computer science quiz challenges and unlock exits to progress through levels.

## 2. Objectives
- Develop a 2D cyberpunk maze game.
- Implement procedural maze generation.
- Create player movement and collision detection.
- Add interactive quiz-based cyber terminals.
- Implement score, lives and countdown systems.
- Create multiple levels and game completion screens.
- Demonstrate computer graphics concepts.

## 3. Gameplay
The player navigates through a maze using WASD or arrow keys. At a cyber terminal, pressing E starts a timed quiz challenge. A correct answer unlocks the exit. The player reaches the exit and presses Enter to continue.

## 4. Main Features
- Cyberpunk-themed main menu.
- Procedurally generated maze.
- Player movement and wall collision.
- Interactive cyber terminal.
- Computer science quiz challenges.
- Countdown timer and lives.
- Score system and level progression.
- Victory and Game Over screens.
- Background music and settings.

## 5. Controls

| Key | Action |
|---|---|
| W / Up Arrow | Move Up |
| S / Down Arrow | Move Down |
| A / Left Arrow | Move Left |
| D / Right Arrow | Move Right |
| E | Access Cyber Terminal |
| Enter | Enter Unlocked Exit |
| ESC | Return to Main Menu |
